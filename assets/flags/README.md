# Route flags

Local SVGs used as mechanical flap faces after DAC and YYZ in the route state:

- `bangladesh.svg`: [Flag of Bangladesh](https://commons.wikimedia.org/wiki/File:Flag_of_Bangladesh.svg), downloaded from Wikimedia Commons.
- `canada.svg`: [Flag of Canada](https://commons.wikimedia.org/wiki/File:Flag_of_Canada.svg), downloaded from Wikimedia Commons.

Both source files are marked public domain on Commons. The SVG artwork is
unchanged; CSS controls its displayed size. Each flag shares the letter faces'
clipped upper and lower halves and rotating leaves. The flag cells keep scrolling
through characters until the route letters settle, then flip directly from a
character to each flag as their final step. Flags flip out when the name returns.
The route has an accessible text description on the board, so the flag images
are decorative.
