# Company logos

Local artwork used beside employer names in the Experience cards:

- `cpi-mark.png`: the owner's [supplied CPI image](https://www.theladders.com/_next/image?url=https%3A%2F%2Fs3.amazonaws.com%2Fcompany-photo.theladders.com%2F3203%2F6943b708-1064-4614-9d71-233d2b22cfb3.png&w=256&q=75). CSS crops the image to show only the CPI symbol, excluding the company wording beneath it.
- `best-buy.png`: original transparent PNG from the header of [Best Buy's corporate logo page](https://corporate.bestbuy.com/best-buy-logo-4/), downloaded from [its high-resolution asset](https://corporate.bestbuy.com/wp-content/uploads/thegem-logos/logo_0717ce843a2125d21ef450e7f05f352e_3x.png).

The source image files and colors are unchanged; CSS scales the logos
proportionally and crops the CPI image. Both use the same compact logo slot.
The adjacent company names identify the employers, so the logo images have
empty alternative text.
